# Karlo harness context

Use the repository's own instructions first. For personal defaults, read only the relevant files under `$AGENT_CONFIG_HOME` (default `~/.config/karlo`).

- Read `CONTEXT.md` for identity and defaults.
- Read `AGENTS.md` for interaction and delivery preferences.
- Read `STACK.md`, `DECISIONS.md`, `INVENTORY.md`, `DESIGN.md`, or `OPERATIONS.md` only when the task needs them.
- Do not load the full personal context for greetings or simple read-only questions.
- Treat harness memory as a cache. Put durable lessons in the appropriate repository or personal context file.
- Keep answers direct. Use bullets for long material. Avoid fluff, neon UI, and unnecessary confirmation.
- State what was checked and what remains unverified. Do not claim a successful check from silence.

Never read or modify Claude Code configuration from this harness pack.
