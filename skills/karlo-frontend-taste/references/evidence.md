## Recorded defaults

These were open in the source notes. The skill resolves them so the next agent does not stop to ask.

- **Icons.** He did not restate the exact target of "these icons". The safe reading is rule 16: they must render, as plain strokes, with no tinted tile. Do not ask again unless a new comment contradicts that.
- **Backdrop.** The masked line-grid is in for the product profile, because he asked for the Orca/NetBird page. Glows, glass, and gradients stay out everywhere.
- **Theme.** Set by the profile. Product starts dark. Brutalist personal and catalog start light. A project design file overrides both.
- **Sparse versus breathe.** These are not in conflict. Sparse means too little content. Breathe means padding inside cells. Fix each with its own tool.
- **Multi-column.** "No multi-column" was said about a phone and homepage list. He later proposed a 2×2 grid himself. Do not ban grids. Ban splitting one list to fill width.
