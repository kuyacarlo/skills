Behavior

Controls that lie, layouts that jump, and states that hide. Click everything.

Layout shift Dead filter Copy buttons Empty controls Link color spill Blank icon tiles Lost phone emphasis

Layout shift on interaction

Fix: one fixed panel height. Watch the bar under each panel as you switch tabs.

Dead filter

Fix: every filter filters, with counts. Try both.

Copy buttons

Fix: copy on the first click. Only the clicked button says Copied.

Empty controls

Fix: drop controls with nothing under them. Say when a page is empty.

Link color spilled everywhere

Fix: link color on inline links only. Card titles underline on hover.

Blank and tiled icons

Fix: plain stroke icons beside the text. Check that they render.

Emphasis lost on phone

Fix: the phone is the desktop transposed. Same order, same highlight.
