Surfaces

Gradients, glows, glass, and shadows used as decoration.

Purple-to-blue gradient hero with halo

Fix: a plain ground from the product palette. Let the content carry the page.

Gradient text

Fix: one solid color. Use size or weight for emphasis.

Glassmorphism over blobs

Fix: a border or a background. Blur only for a real layering problem.

Hairline plus wide shadow, hard offset shadow

Fix: pick an edge or a shadow, not both. Offset shadows only as a deliberate style.

Side-stripe accent card

Fix: remove the stripe unless it marks a status. Then say the status in words.

Neon dark mode

Fix: keep dark, drop the glow. Soft contrast, status as words.

Decorative grid backdrop and extreme radius

Fix: grids only where something gets measured. Scale the radius to the element.

Cream, serif, terracotta

Fix: build the palette from the product's identity. Cream only if it is the brand.
