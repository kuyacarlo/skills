Your existing workflow file works

Point runs-on at a Quarry label. Nothing else in the job changes.

# .github/workflows/build.yml
jobs:
  build:
    runs-on: [quarry, x86_64]
    steps:
      - uses: actions/checkout@v4
      - run: cargo build --release

Logs stay on the runner

The pull request gets a live stream. The full log is written to the runner's disk and kept for 30 days by default.

$ ls /var/lib/quarry/logs/2026-11-18/
build-4812.log   test-4813.log   lint-4814.log
$ du -sh /var/lib/quarry/logs
1.9G    /var/lib/quarry/logs
