Structure

Labels, grids, and layouts that carry no information.

Eyebrow label Badge above headline Icon-card grid Nested cards Numbered steps Command under CTA Hero metric

Eyebrow label

Fix: delete it. The heading already says it.

Badge above the headline

Fix: remove it. Put real news in the changelog.

Equal icon-card grid

Fix: show the product. A real table beats three emoji tiles.

Nested cards

Fix: flatten. One surface, dividers between rows.

Numbered equal-column steps

Fix: a plain step list beside a panel that shows the step for real. Click a step.

Install command under the CTA

Fix: hide it in a popover on the install button, with Copy. Hover or focus it.

Hero metric

Fix: lead with a number only when it explains the product, with its context.
